Official public specification and integration interface for the **SEI OmniSpatial Runtime** by **DPRLAB**. 

This repository defines the open standards, JSON/YAML schemas, and Model Context Protocol (MCP) configuration interfaces required to interface frontier language models (e.g., Claude, Gemini) with cloud-native spatial execution engines for real-time, multi-user simulation.

---

## 🏗 System Architecture

The **SEI OmniSpatial Runtime** acts as the deterministic execution layer bridging abstract spatial specifications ("Blueprint as Code") with live, cloud-hosted runtime instances.
